# University Application Portfolio

## Product Goal

This website is a personal portfolio created for university applications.

The website should help an admissions officer understand:

1. Who this person is.
2. What they care about.
3. How they observe the world.
4. What they have actually done.
5. How their experiences shaped their thinking.

The website is NOT a developer portfolio.

It should feel like:

- an independent magazine
- a documentary project
- an art / architecture portfolio
- a personal editorial publication

---

# Visual Direction

Keywords:

Editorial
Documentary
Minimal
Human
Cinematic
Quiet
Thoughtful
Personal

Avoid:

- SaaS aesthetics
- dashboard UI
- excessive cards
- glassmorphism
- neon gradients
- generic bento grids
- excessive rounded corners
- skill bars
- decorative icons
- AI-looking layouts

The design should feel curated, not generated.

---

# Layout Philosophy

Use generous whitespace.

Not every section needs a container.

Allow content to breathe.

Use asymmetry when appropriate.

Photography should sometimes occupy
40–80% of the viewport.

Use editorial relationships between:

text
image
caption
metadata
whitespace

---

# Grid

Desktop:

12-column grid

Max content width:
1440px

Main text width:
620–760px

Side metadata:
180–260px

Outer margin:
clamp(24px, 5vw, 80px)

---

# Typography

Typography is a primary visual element.

Recommended structure:

Hero title:
clamp(64px, 10vw, 150px)

Project title:
clamp(48px, 7vw, 100px)

Section heading:
32–48px

Body:
16–18px

Caption:
11–13px

Metadata:
11–13px

Use strong contrast between:
serif display typography
and
neutral sans-serif body typography.

Avoid excessive font weights.

---

# Color

Use a restrained palette.

Primary:
near black

Background:
warm white / paper

Secondary:
warm gray

Accent colors should come primarily
from photography and project imagery.

Do not introduce unnecessary UI colors.

---

# Image Treatment

Images are content, not decoration.

Use:

full bleed images
editorial grids
diptychs
triptychs
cinematic crops
portrait / landscape contrast

Maintain image aspect ratio.

Avoid generic rounded image cards.

Captions should be subtle and meaningful.

---

# Projects

Do not represent major projects as cards.

Each major project should feel like
a chapter or editorial story.

Recommended project structure:

01 Context

02 Why

03 Process

04 Observation

05 Outcome

06 Reflection

The most important section is often reflection.

---

# Storytelling

Avoid resume-style writing.

Instead of:

"I participated in X."

Prefer stories that explain:

why
how
what changed
what was learned

The website should reveal personality
through evidence rather than claims.

---

# Motion

Motion must support reading.

Recommended:

fade reveal
clip reveal
slow parallax
image transitions
subtle hover states
page transitions

Avoid:

cursor effects
3D tilt
particle backgrounds
excessive scroll hijacking
constant movement

Animations should generally feel slow,
quiet and intentional.

---

# Navigation

Navigation should remain simple.

Possible navigation:

Index
About
Projects
Visual
Writing

Do not create complex multi-level navigation.

---

# Mobile

Mobile design must be intentionally designed,
not simply stacked desktop content.

Check:

375px
430px
768px
1280px
1440px
1920px

Prioritize:

readability
image crop
section rhythm
typography
spacing

---

# Accessibility

Respect:

prefers-reduced-motion

Use semantic HTML.

Maintain readable contrast.

Images need useful alt text.

---

# Final Review

For every significant page change:

1. Start the development server.
2. Open the page in a browser.
3. Check at 1440px.
4. Check mobile.
5. Check typography hierarchy.
6. Check image cropping.
7. Check whitespace.
8. Check storytelling rhythm.
9. Remove unnecessary UI elements.
10. Remove anything that feels generic or AI-generated.
11. Verify existing content and functionality still work.

Do not consider a page complete
based only on code correctness.
